// 3. Encrypt & Create Bundle
①

SHA-512 Hash

Compute a 512-bit fingerprint of the original file bytes. Stored inside the bundle to verify integrity on decryption.

②

AES-GCM-256 Encrypt

A fresh random 256-bit AES key and 96-bit IV are generated. The file is encrypted with an appended 128-bit authentication tag.

③

RSA-OAEP Wrap Key

The AES session key (32 bytes) is encrypted with the recipient's RSA-2048 public key. The plaintext AES key is never included in the bundle.
