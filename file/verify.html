// Why SHA-512 for File Sharing?
★

SHA-512 — 512 bits

2^512 possible outputs. Collision resistance: no known attacks. Best for sensitive file integrity. Used in this system.

—

SHA-256 — 256 bits

2^256 possible outputs. Widely used, still secure. Used internally for AES key derivation in this system.

✗

MD5 / SHA-1 — Deprecated

Collision attacks are known. Never use these for security-sensitive file verification.
