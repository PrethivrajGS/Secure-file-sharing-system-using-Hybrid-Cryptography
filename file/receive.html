// 3. Decryption Process
①

RSA Unwrap

Your RSA-2048 private key decrypts the wrapped AES session key stored in the bundle. This is the reverse of the sender's RSA-OAEP encryption.

②

AES-GCM Decrypt

The recovered 256-bit AES key and bundle IV are used to decrypt the file bytes. AES-GCM also verifies the 128-bit authentication tag — if the bundle was tampered, this fails.

③

SHA-512 Verify

SHA-512 is recomputed over the decrypted bytes and compared against the hash embedded in the bundle. Match = file is intact and unmodified.
