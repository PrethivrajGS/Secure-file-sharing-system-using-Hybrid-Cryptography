🗝️ RSA Key Pair Generation

Generate a 2048-bit RSA-OAEP key pair. Give your public key to anyone who wants to send you files. Keep your private key secret — it's required to decrypt received files.

// RSA Key Generation
1

Click Generate

Creates a 2048-bit RSA-OAEP key pair using the browser's secure random number generator.

2

Copy Public Key

Share this with anyone who will send you encrypted files. It is safe to share publicly.

3

Save Private Key

Store this somewhere safe. You will need it on the receive.html page to decrypt files.

Algorithm: RSA-OAEP Key Size: 2048-bit Hash: SHA-256 Public Exp: 65537 Format: SPKI / PKCS#8
// How RSA Key Wrapping Works
A

Public Key → Encrypt

The sender uses your public key to encrypt (wrap) the AES session key. Only your private key can unwrap it.

B

Private Key → Decrypt

You use your private key to recover the AES key, then use that to decrypt the actual file.

C

Why Not Encrypt File with RSA?

RSA can only encrypt small data (~190 bytes). So we use AES for the file and RSA only for the small AES key — this is called hybrid encryption.
