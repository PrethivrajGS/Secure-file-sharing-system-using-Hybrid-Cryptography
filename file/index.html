Step 01
Key Generation

Generate a 2048-bit RSA key pair. Share your public key with the sender. Keep the private key secret — it's needed to decrypt files sent to you.

RSA-OAEP · 2048-bit · PKCS#8 / SPKI PEM
📤
Step 02
Encrypt & Send File

Drop a file, paste the recipient's public key. The system hashes with SHA-512, encrypts with AES-GCM-256, and wraps the key with RSA. Download a secure bundle.

SHA-512 + AES-GCM-256 + RSA-OAEP
📥
Step 03
Decrypt & Receive

Paste the secure bundle and your RSA private key. The AES key is recovered, the file is decrypted, and SHA-512 integrity is automatically verified.

RSA unwrap → AES decrypt → SHA-512 verify
✅
Step 04
Integrity Verifier

Independently verify any file's SHA-512 hash against a known digest. Detects tampering, corruption, or any modification — even a 1-bit change in the file.
